# Bolum 0 Uygulama Paketi (v1-2026-guz-alfa)

Bu klasor, Dogal Dil Isleme dersi Bolum 0 kapsamindaki calisan dogrulama kodlarini ve bagimliliklarini icerir.

## Dosyalar
* `main.ipynb`: Ortam dogrulama ve ornek pipeline calistirma not defteri.
* `test_setup.py`: Terminal uzerinden hizli kutuphane ve donanim kontrol betigi.
* `requirements.txt`: Kutuphane bagimliliklari.

## Calistirma

```bash
# 1. Bagimliliklari yukleyin
pip install -r requirements.txt

# 2. Terminal testini calistirin
python test_setup.py

# 3. Not defterini acin
jupyter notebook main.ipynb
```
